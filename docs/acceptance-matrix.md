## Structural evidence limits

The verifier does not compile the target, resolve traits/macros across crates, or prove that a schema-named receiver is globally immutable. It establishes a conservative local syntactic witness: a schema/field-named membership guard (or an unshadowed local returned equality), linked to a direct fallback mutation carrying its key; or an actual returned/propagated unknown-field rejection. A local transformed key qualifies only through a uniquely bound immutable `Ok(local)` template whose every match arm interpolates the parameter. Arbitrary helper arguments, opaque macro bodies, shadowed bindings, discarded comparisons/errors, unsupported module-local resolution and incomplete syntax are not proof. The ownership/liveness matrix adds 28 cases to the retained 61: guard-key/receiver assignments, compound writes, mutable borrows and unresolved key methods invalidate identity; all identifiers in nested helper patterns own their bindings. Uninvoked closure/async/const and local-item bodies cannot supply enclosing execution evidence (closure-call inference remains unsupported). Sequential capture, rejection and body traversal stop after a direct `return`, `break` or `continue`; arbitrary path reachability and alias/callee effects are not inferred. Direct capture/rejection, unshadowed helper and unrelated-mutation controls remain positive. Unknown targets remain missing; the earlier partial-replacement status is unchanged. Broader semantic claims would need compiler-resolved typed/control-flow facts, not another keyword whitelist.

Source admission stays 2 MiB. Semantic analysis is capped at 256 KiB, delimiter depth 64, 256 non-whitespace bytes between statement/list boundaries, and 8 parameters per local helper summary. Analysis is once per admitted file/query group, not per display window. The whole-file literal table and all per-window literal lookup were deleted: literal lookup has **zero table visits and zero table storage**; byte-preserving masking is O(source bytes) time and storage. The bounded AST is O(analysis bytes) storage; branch inspection is bounded by nesting depth. Sorted decision/action witnesses use binary-search window lookup; no unlimited enclosing-context scan is introduced. A 1,200,014-byte, 100,000-literal fixture is executed with an external 5-second / 4-CPU-second / 1-GiB-address-space cap, without a benchmark framework.
